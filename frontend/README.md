# Remote IT Job — Frontend

Frontend của dự án Remote IT Job, xây dựng bằng **Next.js (App Router, SSR)**.

## Chạy

```bash
npm install
cp .env.example .env.local   # nếu cần đổi BACKEND_URL
npm run dev                  # chạy tại :3000
```

## Test

```bash
npm test            # unit test (Vitest)
npm run test:e2e    # e2e test (Playwright)
```
